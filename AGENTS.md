# Agent instructions

## Language

Use English for anything a person may read in the repository or on GitHub. That includes, but is not limited to:

- Pull request titles and descriptions
- README and other documentation
- Code comments
- Commit messages
- Issue text, changelogs, and similar artifacts

Do not mix languages in those surfaces. Keep them in English even when the requester is writing in another language.

Use the language the requester is using (or explicitly asked for) for conversation that is not published as project artifacts: chat replies, status updates, and other private back-and-forth with the requester.
